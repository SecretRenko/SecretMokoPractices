# SecretMokoPractices

用于保存小型练习、实验性代码和不需要单独建立仓库的工具。

## 仓库定位

这个仓库采用练习项目集合（monorepo）的方式组织内容。每个练习应放在独立目录中，保留自己的说明、依赖和运行方式，避免不同实验的文件混在仓库根目录。

建议按主题扩展：

```text
SecretMokoPractices/
├── chemistry/
├── machine-learning/
├── python/
├── web/
└── misc/
```

只在实际加入项目时创建对应目录，不保留没有内容的占位文件。

## 新增练习的约定

每个练习目录至少应包含一个 `README.md`，说明：

- 练习目标；
- 所需环境与依赖；
- 运行方式；
- 当前完成程度或已知限制。

生成文件、缓存、密钥和本机环境配置不应提交。若某个练习发展为长期维护的完整项目，可以再迁移到独立仓库。
